## 原則

- 静的な内容はWebサーバーが返し、動的な処理が必要なときだけアプリケーションサーバーに頼む。
- データの永続化はデータベースが担う。

## ネットワーク

<Figure src="/figures/n5-2-3-2919.webp" alt="ネットワーク。建物内などのLAN（Local Area Network）同士を、広域のWAN（Wide Area Network）がつなぐ" caption="LAN同士をWANがつなぐ" />

| 種類 | 内容 |
| --- | --- |
| LAN（Local Area Network） | 建物内など限られた範囲のネットワーク |
| WAN（Wide Area Network） | 離れたLAN同士をつなぐ広域のネットワーク |

## Webの3層構造

<Figure src="/figures/n5-2-3-2920.webp" alt="Webサービスの3層構造。Webブラウザの要求をWebサーバーが受け、静的な内容はそのまま返す。動的な処理が必要ならアプリケーションサーバーに要求し、アプリケーションサーバーは必要に応じてデータベースに問い合わせる" caption="ブラウザ → Webサーバー → アプリケーションサーバー → データベース" />

| 層 | 役割 |
| --- | --- |
| Webサーバー | ブラウザからの要求を受ける。静的な内容はそのまま返し、動的な処理が必要ならアプリケーションサーバーに要求する |
| アプリケーションサーバー | 要求に応じて演算やデータベースへの問い合わせを行い、結果を返す |
| データベース | データを記録・参照・変更・削除する |

## データベース

<Figure src="/figures/n5-2-3-2902.webp" alt="データベースの概念図。データベース管理システム（DBMS）が、メモリとディスクの両方とやり取りする" caption="DBMSがメモリとディスクを使い分ける" />

| 要素 | 役割 |
| --- | --- |
| DBMS（データベース管理システム） | データベースの作成・更新・参照を提供するソフトウェア。トランザクション制御、バックアップ・リカバリも担う |
| ディスク（ストレージ） | データを永続化するハードウェア。机の「引き出し」にあたる |
| メモリ | 高速に読み書きできるが揮発性。机の「テーブル」にあたる。データのキャッシュや、ストレージに書き込む前の更新内容を貯めるのに使う |
