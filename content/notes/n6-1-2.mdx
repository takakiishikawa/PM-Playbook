## 原則

- まず取り組むべきは仮説検証型のアプローチ。
- データの尺度によって適した分析手法が異なり、使えない手法もある。
- 平均値は外れ値に引きずられる。伝えたいことに応じて、平均値・中央値・最頻値を使い分ける。

## データの種類と分析アプローチ

| データ | 測るもの | 例 |
| --- | --- | --- |
| 定量データ | 消費者行動の広さ。数値で把握できる情報 | 認知率、PV数（アンケート、アクセスログ） |
| 定性データ | 消費者行動の深さ。数値に表せない質的な情報 | 購入した商品のどこが気に入ったか、なぜこの店でよく買うのか（インタビュー、行動観察） |

| アプローチ | 内容 |
| --- | --- |
| 仮説検証型 | 仮説を先に立て、それが正しいかを分析で検証する |
| 仮説探索型 | さまざまな観点で分析し、特徴的な違いや変化を見つけて仮説づくりに活かす |

| | 検証型 | 探索型 |
| --- | --- | --- |
| 定量データ | アンケート（選択肢式）、A/Bテスト、アクセスログ解析 | テキストマイニング、アクセスログ解析 |
| 定性データ | アンケート（自由記述式）、ユーザビリティテスト、グループインタビュー、デプスインタビュー | 行動観察、ソーシャルリスニング、デプスインタビュー |

同じ調査手法でも、サンプル数や設計次第で分類は変わることがある。

## データの尺度

<Figure src="/figures/n6-1-2-2087.webp" alt="データの尺度。非数値の名義尺度（分類）と順序尺度（分類・大小比較）、数値の間隔尺度（数値差も扱える）と比例尺度（比率も扱える）に分け、それぞれ具体例を示す" caption="尺度によって使える分析が変わる" />

| 尺度 | できること | 例 |
| --- | --- | --- |
| 名義尺度（非数値） | 分類 | 性別、プロダクトのカテゴリ |
| 順序尺度（非数値） | 分類、大小比較 | 5段階評価、満足度（非常に満足〜非常に不満）、優先度（低・中・高） |
| 間隔尺度（数値） | 分類、大小比較、数値差 | 気温、アプリの使用開始時刻、製品の発売年 |
| 比例尺度（数値） | 分類、大小比較、数値差、比率 | 売上金額、利用時間、ページビュー数 |

## 記述統計

統計学には、データを集計して特徴を表す記述統計学、限られた標本から母集団の性質を推測する推測統計学、母数が確率的に動くとみなすベイズ統計学がある。データの特徴をつかむには、まず記述統計を使う。

| 統計量 | 内容 |
| --- | --- |
| 平均値 | 合計をデータの個数で割った値。中心傾向を示すが、外れ値に引きずられやすい |
| 中央値 | 順に並べたとき中央に位置する値。外れ値の影響を受けにくい |
| 最頻値 | 最も頻繁に出現する値。名義尺度や順序尺度にも使える |
| 最大値・最小値 | 最も大きい値と小さい値 |
| 四分位数 | 順に並べたときの25%・50%・75%の位置の値。ばらつきや分布を示す |
| 標準偏差 | 平均値の周りにどれくらい散らばっているかを示す |

例：年収500・500・500・550・550・600万円の従業員に、年収1億円のCEOが加わった会社。

<Figure src="/figures/n6-1-2-2090.webp" alt="平均値の例。従業員7人の年収を人のアイコンで並べる（500・500・500・550・550・600万円と、CEOの1億円）。平均値は約1886万円で、外れ値に引きずられて一般的な従業員を反映しない" caption="平均値：外れ値に引きずられる（約1886万円）" />

<Figure src="/figures/n6-1-2-2091.webp" alt="中央値の例。同じ7人を年収順に並べ、ちょうど真ん中の人の550万円が中央値。外れ値の影響を受けにくい" caption="中央値：真ん中の人の値（550万円）" />

<Figure src="/figures/n6-1-2-2092.webp" alt="最頻値の例。同じ7人のうち最も多く出現する年収は500万円。アンケートの回答など名義尺度・順序尺度にも使える" caption="最頻値：最も多い値（500万円）" />

<Figure src="/figures/n6-1-2-2093.webp" alt="外れ値の例。CEOの年収1億円は、他の値と比べて大きく外れた外れ値。外れ値のうち、入力や測定のミスで説明できるものが異常値" caption="外れ値：他から大きく外れた値（CEOの1億円）" />

| 使う統計量 | 向いている場面 |
| --- | --- |
| 平均値 | データ全体やデータ間で比較したい |
| 中央値 | 極端な外れ値がある |
| 最頻値 | 大きなばらつきがある |

## 度数分布表とヒストグラム

度数分布表は、データを一定の幅（階級）で区切り、各階級に含まれる個数（度数）を数えた表。グラフにしたものがヒストグラム。分布の形が見えるので、平均値・中央値・最頻値のどれで伝えるべきかを判断しやすい。

<Figure src="/figures/n6-1-2-2096.webp" alt="ヒストグラムの例：所得金額階級別の世帯数の分布（2021年調査）。分布は右に裾が長く、平均値（564万円）は中央値（440万円）や最頻値（300〜400万円）より高い位置にくる" caption="分布が偏ると、平均値は実態より高く出る" />
