## 原則

- <Mark>**いきなり結論だけ共有するのではなく、思考過程も共有する。**</Mark>
- 意思決定のプロセスを可視化してドキュメントにすると、他の人でも質の高い意思決定ができる。
- メンバーと合意形成をして、強みを引き出すのもPMの大事な仕事。

## 合意形成が大事な理由

| 理由 | 内容 |
| --- | --- |
| 意思決定の質の向上 | メンバーやステークホルダーからのフィードバックがヒントになる |
| チームの信頼構築 | 信頼関係ができ、意思決定が効率化する |
| 属人化リスクの軽減 | PMが不在になったとき、誰も決められなくなる事態を防ぐ |
| コミットメント強化 | 一緒に考えている感覚があると、協力してもらいやすい |
| 要件のひっくり返し防止 | 一度決めたことを後から変更されるリスクを減らす |

## プロセス：合意を形成する

<Steps>
  <Step title="ロジックを可視化する">ファクト収集・課題特定・解決策の設計など、意思決定の背景を見える化する</Step>
  <Step title="ドキュメントにする">そのドキュメントを持って関係者に共有する</Step>
  <Step title="フィードバックを集める">結論の前に意見をもらう</Step>
  <Step title="合意形成の会議をする">論点を確かめ、決める</Step>
  <Step title="進捗を随時共有する">決めた後も状況を伝え続ける</Step>
</Steps>
