## 原則

- GA4の基本の単位は「ユーザー」と「イベント」。ページ閲覧以外の行動もあわせて取ると、サイト内での行動や態度の変化を理解しやすい。
- すべてのレポートは「ディメンション（集計の軸）」と「指標（集計の単位）」の組み合わせでできている。
- UAと同じ名前でも定義が変わった指標がある。比べるときは要注意。

## GAとSQLの使い分け

| | GA（アクセス解析） | SQL（ログデータ分析） |
| --- | --- | --- |
| 強み | 行動パターン、訪問頻度、滞在時間、離脱率を簡単に把握できる。Googleの他サービスと統合し、マーケティングとの関係を見られる | データベースに直接アクセスし、特定の問いに答えるカスタムクエリを書ける。大量データを扱える |
| 必要なスキル | コーディング不要。グラフで直感的に見られる | SQLの知識が要る |
| 向いている分析 | 一般的なWeb分析、ユーザー行動の追跡 | ユーザー単位の詳細な分析 |

## 計測の仕組み

<Figure src="/figures/n6-3-1-1937.webp" alt="GA4のアクセス解析の考え方。ユーザーはWebサイト内でページ閲覧以外にもさまざまな行動（イベント）を行い、サイトを理解して目的達成に向かう。基本の単位はユーザーとイベント" caption="基本の単位は「ユーザー」と「イベント」" />

イベントは「何をしたか」というアクション、パラメータはその「詳細や条件」。1つのイベントに複数のパラメータがつく（例：page_viewに、表示したページのURLや前のページのURL）。

<Figure src="/figures/n6-3-1-1938.webp" alt="GA4の計測の仕組み。page_viewなどのイベントに、page_location（表示したページのURL）やpage_referrer（前のページのURL）などのパラメータが付く" caption="イベントに、詳細を表すパラメータが付く" />

| イベントの種類 | 内容 | 例 |
| --- | --- | --- |
| 自動で取得できる | 設定なしで計測される | 初回訪問、ページ表示、セッション開始、エンゲージ |
| 管理画面の設定が必要 | 自動で取れるが有効化が要る | 90%までのスクロール、外部リンクのクリック、サイト内検索、動画の再生、ファイルのダウンロード、フォームの開始・送信 |
| 推奨イベント | 業種ごとに名前が決められている | ログイン、会員登録、カート追加、購入、チュートリアルの完了 |
| カスタムイベント | 独自の名前とパラメータで計測する | ページへの記述やタグ管理ツールの設定が必要 |

## 主なディメンションと指標

<Figure src="/figures/n6-3-1-1944.webp" alt="ディメンションと指標。GAのレポートは表の行にあたるディメンション（集計の軸）と、列にあたる指標（集計の単位）の組み合わせでできている" caption="レポート = ディメンション（軸）× 指標（単位）" />

| 分類 | 主なもの |
| --- | --- |
| ユーザーのディメンション | 年齢、性別、インタレストカテゴリ、新規／既存、国・地域、デバイス、OS、ブラウザ、言語 |
| 集客のディメンション | チャネルグループ、メディア、参照元、キャンペーン（セッション単位と、最初に獲得したとき単位がある） |
| ページのディメンション | ページタイトル、ページURL、直前のページ、ランディングページ |
| セッションの指標 | セッション数、エンゲージのあったセッション数（10秒以上の滞在、コンバージョン、2PV以上のいずれか）、エンゲージメント率、直帰率、平均エンゲージメント時間、コンバージョン率 |
| ユーザーの指標 | アクティブユーザー数、新規ユーザー数、ユーザーあたりのイベント数、ユーザーコンバージョン率 |
| ライフタイムの指標 | 初回訪問以降のエンゲージメントセッション数・時間・購入数、LTV |
| ページの指標 | 表示回数、閲覧開始数、離脱数 |
| eコマースの指標 | 商品一覧・詳細の表示、カート追加、チェックアウト、収益、購入者数 |

### UAから定義が変わった指標

| 指標 | UA | GA4 |
| --- | --- | --- |
| ユーザー | 来訪ユーザーをすべて数える | 1秒以上画面を前面に表示したアクティブユーザー |
| セッション | 30分操作がない、別の参照元から再訪、日付をまたぐ、で別セッション | 30分操作がない場合のみ別セッション |
| コンバージョン | 1回の訪問で何度起きても1と数える | 起きた行動の数を数える |
| 直帰率 | 1ページだけで離脱した割合 | エンゲージのなかったセッションの割合（100% − エンゲージメント率） |

## 標準レポート

| レポート | 確認できること |
| --- | --- |
| リアルタイム | 直前の行動。SNS投稿の瞬間的な影響など |
| 集客 | チャネル・メディア・参照元・キャンペーン別のパフォーマンス。新規獲得と刈り取りの目的別 |
| エンゲージメント | エンゲージメント指標の推移、イベントやコンバージョンごとの発生状況 |
| 収益化 | 収益、購入者数、平均購入額、商品カテゴリ・商品ごとの購入状況 |
| 維持率 | 新規ユーザーのリピートを促す施策の効果、リピートする割合 |

## 探索レポート

| テンプレート | 使いどころ |
| --- | --- |
| 自由形式 | 最も基本。表やグラフで行と列を組み替え、指標を並べて比べる |
| ファネルデータ探索 | 開始ページから到達ページまでのファネルを描き、どのステップで離脱しているかを見る |
| 経路データ探索 | 特定のページの前後の遷移を深掘りする |
| セグメントの重複 | 「コンテンツAを見てBも見たユーザー」など、セグメントの重なりを見る |
| コホートデータ探索 | 初回訪問日でユーザーをグループ化し、その後の訪問やコンバージョンを追う |
| ユーザーのライフタイム | 初回獲得日やメディアと、LTVなどの全期間の指標を見る |
