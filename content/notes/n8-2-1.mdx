## 原則

- <Mark>**PMは概要を把握したうえで「アンテナ」を張り、必要に応じて法務などの専門家に適切なタイミングで確認・相談する。**</Mark>
- データの利活用は、個人単位・行動単位の具体と、統計化・要約した抽象を行き来する。個人単位のデータにはリスクがある。
- 個人情報保護とプライバシー保護は別に考える。法律で守られる範囲だけを守ればよいわけではない。

## ルールの流れ

デジタル技術の発展で個人情報の収集と利用が容易になり、それに合わせてルールも作られてきた。

| 年 | 出来事 |
| --- | --- |
| 1980年 | OECDがプライバシー保護と国際的なデータ流通のガイドラインを制定 |
| 2003年 | 日本で個人情報保護法が成立 |
| 2016年 | 欧州でGDPR（一般データ保護規則）。データ主体の権利を大幅に強化し、罰則を厳格化した |
| 2022年 | 日本の改正個人情報保護法が全面施行。個人の権利の保護と活用の強化、越境データ、AI・ビッグデータへの対応 |

日本の個人情報保護法は、技術の発展に合わせて3年ごとに見直す規定がある。

### GDPR

EU市民の個人情報がグローバルに保護されることを求める規則で、EU域外の事業者にも適用される。Webサイトのユーザーに個人情報の利用への同意を求める必要があり、Cookieで得られる個人データも対象。違反すると、全世界年間売上高の4%以下か2000万ユーロ以下の高いほうの制裁金が科される。

### 2020・2021年改正のポイント

- 個人の権利（利用停止・消去・開示請求など）の拡大
- 漏洩時の委員会への報告と本人への通知の義務化
- 「仮名加工情報」の創設
- ペナルティの引き上げ
- 3本の法律を1本に統合し、所管を個人情報保護委員会に一元化

## 個人情報とは

特定の個人を識別できる情報。他の情報と容易に照合でき、それで個人を識別できる情報も含む。たとえば顧客IDつきの購買履歴は、顧客DBと突き合わせれば個人を特定できるので、顧客DBを持つ企業にとっては個人情報になる。

<Caution>Cookie単体では個人を識別できないので個人情報にあたらない。ただし、ログイン中の会員情報と紐づけて個人を識別できる場合は、Cookieで集めた閲覧履歴なども個人情報になる。2022年の改正で、Cookieなどの個人関連情報を第三者に提供するには本人の同意が必要になった。</Caution>

| 分類 | 内容 | 主な義務 |
| --- | --- | --- |
| 個人情報 | 特定の個人を識別できるもの | 利用目的の特定、目的外利用の制限、適正な取得 |
| 個人データ | データベースなどを構成する個人情報 | 安全管理措置、委託先の管理、第三者提供の制限 |
| 保有個人データ | 開示などの権限を持つ個人データ | 公表、開示、訂正・追加・削除、利用停止 |

| | 個人情報 | 仮名加工情報 | 匿名加工情報 |
| --- | --- | --- | --- |
| 加工 | なし | 他の情報と照合しない限り個人を識別できない。対照表と照合すれば本人が分かる | 個人を識別できず、復元もできない |
| 利用目的の制限 | あり | あり（目的の変更は可能） | なし |
| 漏洩等の報告 | あり | 対象外 | 対象外 |
| 第三者提供時の同意 | 必要 | 原則第三者提供禁止 | 不要 |
| 開示・利用停止等の請求対応 | あり | 対象外 | 対象外 |

仮名加工情報の創設で、企業内部での分析を目的とした利用条件が緩和された。

## 第三者提供と委託

個人データの第三者提供には、原則として本人の同意が要る。すでに同意を得ている利用目的の範囲内で、入力・分析・商品発送などの業務を委託する場合は第三者提供にあたらない。ただし委託先に必要かつ適切な監督を行う。

委託契約で決めておくこと：業務内容と利用目的、目的外利用の禁止、秘密保持、契約終了時の返還・廃棄、漏洩時の報告、委託元による監査や情報提供、再委託の可否と条件。

## 実務での同意の取り方

| 場面 | 注意点 |
| --- | --- |
| インタビュー | 参加同意書を用意する。開示された情報の秘密保持と目的外利用の禁止、回答や画像の記録・利用への同意を得る |
| アンケート | 個人情報を取るなら、データ項目と利用目的を示して同意を得る。取らない場合も匿名である旨を示し、不安を与えない |
| システムログ | 利用規約でデータ項目と利用目的を示して同意を得る。変わったら再度同意を得るための通知をする |

<Note title="トラブル事例">あるキャリア支援サービスで、同意が不十分なまま応募者のデータをもとにしたスコアを第三者に提供し、問題になった。ハッシュ化しても、他のデータと照合して個人を識別できれば個人情報になる。</Note>

## ユーザーの感覚の変化

匿名掲示板から、配信者の顔出し、購買履歴を使ったレコメンド、実名での交流、位置情報の共有へと、ユーザーは利便性と引き換えに個人情報を開示し、その恩恵を受けるようになってきた。各社は、データをどう使い、どう守るかを説明するプライバシーガバナンスのコミュニケーションに取り組んでいる。
