## 原則

- 市場・顧客 → 競合 → 自社の順番で考える。
- ビジネスの流れには共通項がある。それを知っておくと、現状の背景の理解や仮説立てに活かせる。

## 事業部長の視点

ビジネスの流れを俯瞰して捉えるために、事業部長の視点で観点を押さえる。

<Figure src="/figures/n1-3-4-3128.webp" alt="筋の良い仮説を立てるために必要な観点（事業部長の視点）。市場とターゲットから顧客ニーズの仮説を、競合商品・サービス、バリューチェーン、会計数値、競争力から提供価値の仮説を立てる。外部環境は両方に影響する" caption="顧客ニーズと提供価値、それぞれの仮説に必要な観点" />

| 捉えたいもの | 必要な観点 |
| --- | --- |
| 顧客ニーズの仮説 | 市場、ターゲット |
| 提供価値の仮説 | 競合商品・サービス、バリューチェーン、会計数値、競争力（シェア） |
| 両方に影響するもの | 外部環境 |

## 原因仮説のパターン

問題が起きたとき、「その背景にはこんな原因があるのでは」と仮説を立てるための型。

| パターン | 問い |
| --- | --- |
| 市場 | 市場全体や対象市場が縮小していないか。魅力度が下がっていないか |
| ターゲット | ターゲットセグメントの魅力度が下がっていないか。一部を競合に攻められていないか |
| サービス提供 | 顧客に魅力を届けられているか。ニーズを満たせているか。競合と差異化できているか |
| バリューチェーン | 顧客価値を継続的に提供するバリューチェーンを作れているか。KSF（Key Success Factor）を強化できているか。改善余地はないか |
| 組織 | バリューチェーンを支える組織、戦略、組織構造・運営、社員の価値観・社風に原因はないか |
| 外部環境 | PEST（政治・経済・社会・技術）の観点で大きな変化はないか |

## 3Cで整理する

1. 市場・顧客を分析する：市場はどう変化しているか、顧客は何を求めているか
2. 競合を分析する：顧客の要望に、競合がどこまで対応しているか
3. 自社を分析する：競合と比べて、自社はどこまで対応できているか

## 推論力を高める

分析とは「事実」と「事実同士の関係性」を推論で解明していくプロセス。「あれはあれ、これはこれ」では何の示唆も出ない。

<Figure src="/figures/n1-3-4-2961.webp" alt="推論力なしでは「漬物の売上が伸びる」「タオルの売上が伸びる」を別々に見て示唆が出ない。推論力ありでは「何か関係があるかもしれない」と考え、気温が上がると両方の売上が伸びると読み解き、天気予報で気温が高い日に漬物とタオルを店頭の目立つ場所に置くという打ち手が出る" caption="関係性を読み解くと、打ち手が出る" />

帰納法は複数の出来事とその結果から規則性を見つける。演繹法は一般論を使って出来事の結果を推測する。

<Figure src="/figures/n1-3-4-2963.webp" alt="帰納法と演繹法の整理。帰納法はA・B・Cなど複数の出来事から共通点をまとめる。演繹法は一般論（A＝B、B＝C）から結論（A＝C）を導く" caption="帰納法と演繹法" />

集めた事実から帰納法で共通点を見つけて方針を出し、演繹法で各部門の個別方針に落とし込むと、方針と施策に一貫性が保たれる。

<Figure src="/figures/n1-3-4-2965.webp" alt="演繹法と帰納法の合わせ技。帰納法で「敏感肌の女性は華やかさを感じる化粧品を求めている」という共通点を見つけ、「華やかさを感じる敏感肌用化粧品」という方針を出す。演繹法で、高級感のあるパッケージ、百貨店チャネル、女性ファッション誌とのタイアップといった各部門の方針に落とす" caption="帰納法で方針を出し、演繹法で施策に落とす" />
