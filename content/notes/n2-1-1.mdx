## 原則

- プロダクト戦略とは、「どんな価値を、どの顧客に、どのように提供し、持続的に成長させるか」を示す指針。
- ここでいうプロダクトは有形のモノに限らない。SaaSのようなソフトウェア、オンラインプラットフォーム、教育プログラムやコンサルティングのような無形サービスも含む。
- プロダクト戦略は上位の戦略と常に影響し合う。整合性を保ち続ける。

## 企業戦略・事業戦略との関係

| 階層 | 決めること |
| --- | --- |
| 企業戦略 | 事業領域、ブランド構築の大きな方向性 |
| 事業戦略 | 収益モデル、マーケットポジショニング |
| プロダクト戦略 | 対象顧客、差別化要素、提供価値の定義 |

## 構成要素

| 要素 | 内容 |
| --- | --- |
| ターゲット顧客 | デモグラフィックだけでなく、心理的特徴や行動特性にも着目する。課題と欲求を深掘りする |
| 価値提案 | 機能一覧ではなく、顧客が使うことでどんな良い変化が起こるかを言語化する |
| マーケット・競合分析 | 市場の成長と競合の強み・弱みを把握し、自社の強みが活きる差別化ポイントを見出す |
| ライフサイクルを踏まえた戦略 | 今どのフェーズにいて、次にどこへ進むかを見極めて立案する |
| 成長戦略・収益モデル | 新規獲得・アップセル/クロスセル・新市場参入のどれを狙うか。サブスクリプションか従量課金か |

## プロダクトライフサイクルと戦略

| 段階 | 特徴 | 主な戦略 |
| --- | --- | --- |
| 導入期 | 認知度が低い | 認知度を高める。無料トライアルや限定的なキャンペーン |
| 成長期 | 売上・ユーザー数が増加 | 市場シェアの拡大と顧客基盤の構築。機能拡充やサービス品質の向上 |
| 成熟期 | 競合が増加 | 価格競争や機能追加による差別化の強化 |
| 衰退期 | 売上が減少 | 新市場への展開やリニューアル。撤退や新プロダクトへの移行も検討する |
