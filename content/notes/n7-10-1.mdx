## 原則

- <Mark>**メンバーの成熟度に合わせて、リーダーシップのスタイルを変える。**</Mark>
- 混乱期はPMもメンバーも苦しいが、形成段階を知っていれば焦らずに対処できる。
- 曖昧な目標では、メンバーは同じゴールに辿り着けない。チームが目指す理想を誰もが理解できる形で言語化する。

## SL理論（状況対応型リーダーシップ）

指示的行動と援助的行動の多さで、リーダーシップを4つのスタイルに分ける。メンバーの成熟度が低いほど指示型、高いほど委任型が合う。

| スタイル | 指示的行動 | 援助的行動 |
| --- | --- | --- |
| 指示型 | 多い | 少ない |
| コーチ型 | 多い | 多い |
| 援助型 | 少ない | 多い |
| 委任型 | 少ない | 少ない |

指示型ではトップダウンの働きかけが顕著になり、委任型では権限の一部をメンバーに移譲し、メンバーが自走する。

## タックマンモデル

| 段階 | 状態 |
| --- | --- |
| 形成期 | チームが発足し、目的を聞かされた段階。メンバーがそれぞれ違う方向を向き、実現したいイメージも曖昧 |
| 混乱期 | お互いを知るため議論が活発になる。意見の対立や離脱が起き、ヒューマンマネジメントにかける時間が増える |
| 統一期 | 共通認識が確立する。個々の能力を理解して補い合い、同じ目標に向かう意識が芽生える |
| 機能期 | 成果を出せる体制で動き出す。メンバーが自走して目標に進む |
| 散会期 | 目的を達成し、チームが終結する |

チームには変化がつきもので、そのたびに混乱と統一を繰り返しながら成果を出せるようになっていく。

## 集権型と分散型のマネジメント

| 型 | 向いているチーム | 注意点 |
| --- | --- | --- |
| 集権型 | 関係が成熟していないチーム。リーダーが細かく指示し、タスクをこなしてもらうほうがスムーズ | 意思決定権が1人に集まり、リーダーが休むとメンバーが動けなくなる |
| 分散型 | スキルが高く安定期のチーム。細かな指示はかえってモチベーションを下げる | 人数が増えたり権限移譲が進んだりすると、権限範囲が曖昧になり、コンフリクトで意思決定に時間がかかる |

メンバーが自律的に進行を考えられるようになったら、コーチ型 → 援助型 → 委任型へと徐々に移行する。コミュニケーションを通じて、良いバランスを調整し続ける。

## メンバーの育成

- チームが目指す理想を言語化し、誰もが理解できる形で示す
- 特定のスキルや経験を伸ばしたいメンバーには、それを支援する役割と責任を与える
- 成果を上げている分野を特定し、改善の余地を指摘する

## 心理的安全性のチェックリスト

1. 目的・目標を組織やチームで共有できている
2. 意見の不一致を建設的に捉えられるファシリテーションができる
3. トラブルが起きたとき、相手を責める言動にならないよう努められる
4. 事前に相談したり、悩みを打ち明けたりできる機会を設けている
5. サポートが必要なとき、助けを求められる
6. アイデアを出し合うとき、他者の意見を否定しない会話ができる
7. 感謝や賞賛を気軽に伝えられる
8. 一人ひとりの個性や強みを活かす場を提供している
9. 「自分勝手な発言」ではなく「好影響を与える率直な発言」ができる
10. 相手に失礼のない、常識ある態度で接している
11. 雑談や研修など、業務以外での交流の場がある
12. チームが心理的安全性について理解する場をつくれる

## PMに求められる人間力

| 資質 | 内容 |
| --- | --- |
| スチュワードシップ | 勤勉で面倒見がよく、誠実であること |
| チーム | 個人ではなく、協働するチームに倫理に則って貢献すること |
| 適応と回復力 | 変化に対応し、挫折や失敗から迅速に回復すること |
| リーダーシップ | 個人とチームのニーズを支える存在であること |
| チェンジ | 変革を実現する挑戦の姿勢を持つこと |
